# Kitchen — frontend

Frontend de l'application Kitchen : Vite + React + TypeScript, Tailwind CSS, shadcn/ui (Radix UI) copié dans le repo, React Hook Form + Zod, next-themes (clair/sombre/système).

## Scripts

```bash
npm run dev        # serveur de dev
npm run build       # build de production
npm run test         # suite de tests (Vitest)
npm run typecheck  # vérification TypeScript
npm run lint        # oxlint
```
